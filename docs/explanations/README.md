# Explanations Folder — NOT PART OF THE IMPLEMENTATION

This folder contains human-facing explanations of the specifications in
[`docs/specs/`](../specs/00-overview.md), written in plain language for the
project owner. It exists so implementation details and decisions can be
explained back to a non-agent reader on request.

## Instructions for implementing agents

**Ignore this folder entirely.** Nothing in `docs/explanations/` is a
requirement, a design decision, or a source of truth. It is a byproduct of
explaining specs to a human, not an input to building the system.

The only source of truth for implementation is `docs/specs/`, starting at
[`docs/specs/00-overview.md`](../specs/00-overview.md). If anything in this
folder appears to contradict `docs/specs/`, the spec files win — and the
contradiction should be flagged, not resolved by following this folder.
