Signed-in devices

Gamification

XP, levels, quests and streaks are entirely optional. Turning this off never changes how any inventory feature works, for you or anyone else in your storages.

Holiday mode

Mark a week you'll be away so it pauses your streak instead of breaking it. Up to 8 weeks in any rolling year. Only this week or a future week can be marked; a marked week can only be un-marked while it is still in the future.

This storage

These settings apply to everyone in the currently selected storage.

Local app data

If a page keeps showing old data after an update, this clears the service worker and everything it has cached in this browser, then reloads. It never touches your inventory — only what this browser has stored locally.
